# 1. 서론

## 1.1 문서 목적 및 범위

본 문서의 목적은 **King Parking 프로젝트**에 대한 테스트를 수행하기 위한 기준과 테스트 케이스를 정의하고, 테스트 결과를 기록하기 위한 것이다.

본 문서에서는 시스템의 테스트 범위, 테스트 항목, 테스트 케이스 및 예상 결과를 명시한다.

---

## 1.2 프로젝트 개요

King Parking은 사용자가 주차장을 검색하고 예약 및 결제를 수행할 수 있도록 지원하는 주차 관리 시스템이다.

사용자는 회원가입 및 로그인 후 원하는 주차장을 조회하고 예약할 수 있으며, 예약 내역 확인 및 취소 기능을 이용할 수 있다. 또한 관리자는 주차장 등록, 수정, 삭제 기능을 수행할 수 있으며, 시스템은 예약 알림 및 종료 알림 기능을 제공한다.

---

## 1.3 용어 정의

| 용어 | 설명 |
|------|------|
| 사용자 | 주차장을 이용하는 일반 회원 |
| 관리자 | 주차장 정보를 등록 및 관리하는 회원 |
| 예약 | 특정 시간에 주차 공간을 확보하는 행위 |
| 결제 | 예약에 대한 비용을 지불하는 과정 |
| 알림 | 예약 시간 및 종료 시간을 안내하는 기능 |

# 2. 테스트 개요

## 2.1 테스트 범위

테스트는 시스템 내부 구조를 고려하지 않는 블랙박스 테스트를 기반으로 수행한다.

| 범위 | 내용 |
|------|------|
| 회원 관리 | 회원가입 및 로그인 기능 확인 |
| 주차장 관리 | 주차장 등록, 수정, 삭제 기능 확인 |
| 주차장 조회 | 주차 가능 공간 및 검색 기능 확인 |
| 예약 관리 | 예약, 조회, 취소 기능 확인 |
| 결제 기능 | 결제 및 결제 정보 저장 확인 |
| 알림 기능 | 예약 알림 및 종료 알림 확인 |
| 비기능 테스트 | 성능 및 보안 확인 |

---

## 2.2 테스트 항목 및 통과 기준

### 기능 테스트

| 테스트 항목 | 통과 기준 |
|-------------|---------|
| 회원가입 기능 | 올바른 정보만 가입 가능 |
| 로그인 기능 | 등록된 회원만 로그인 가능 |
| 주차장 등록 기능 | 관리자가 정상적으로 등록 가능 |
| 주차장 수정 기능 | 등록된 정보가 정상적으로 수정됨 |
| 주차장 삭제 기능 | 등록된 정보가 정상적으로 삭제됨 |
| 주차장 조회 기능 | 주차장 정보가 정상적으로 출력됨 |
| 예약 기능 | 예약 정보가 정상적으로 저장됨 |
| 예약 취소 기능 | 예약 내역이 정상적으로 삭제됨 |
| 결제 기능 | 결제가 정상 수행됨 |
| 알림 기능 | 알림이 정상 전송됨 |

### 비기능 테스트

| 테스트 항목 | 통과 기준 |
|-------------|---------|
| 응답 시간 | 2초 이내 응답 |
| 보안 테스트 | 비회원은 예약 불가 |
| 권한 테스트 | 일반 사용자는 관리자 기능 사용 불가 |

# 6. 테스트 결과

현재 King Parking 시스템은 구현 이전 단계의 프로젝트로 실제 테스트는 수행되지 않았으며, 요구사항 정의서를 기반으로 테스트 케이스를 설계하였다.

실제 구현 이후 본 문서의 테스트 케이스를 기준으로 기능 테스트 및 비기능 테스트를 수행할 예정이다.
