## 1. 서론
### 1.1 문서의 목적 및 범위

본 문서는 King Parking 시스템 개발을 위해 필요한 요구사항을 정의하는 것을 목적으로 한다.
본 문서는 시스템이 제공해야 할 기능적 요구사항과 비기능적 요구사항, 인터페이스 요구사항을 포함한다.

요구사항 정의서는 소프트웨어 개발 과정에서 기준이 되는 핵심 문서이다

### 1.2 프로젝트 개요

#### 1.2.1 프로젝트 정의

King Parking 시스템은 사용자와 주차장을 연결하여 주차 공간을 효율적으로 관리하는 온라인 서비스이다.

#### 1.2.2 주요 기능 설명 

| ID | 설명 |
|------|-----------------------|
| F01 | 주차 공간 등록 및 관리 |
| F02 | 주차 공간 예약 |
| F03 | 주차 요금 결제 |
| F04 | 실시간 주차 현황 확인 |
| F05 | 예약 시간 알림, 주차 종료 알림 | 

### 1.3 용어 정의
* 사용자: 주차장을 이용하는 일반 회원
* 관리자: 주차장을 등록 및 관리하는 사용자
* 예약: 특정 시간에 주차 공간을 확보하는 행위

### 1.4 참조 문서

* [King Parking] 프로젝트관리계획서
