## Project 2. 대상 시스템 품질 요소 추정하기



## **(1) 사용자가 원하는 기대치는 무엇인가?**

사용자는 주차 공간을 빠르고 편리하게 찾고 미리 예약해둘 수 있는 시스템을 기대합니다.

특히 실시간으로 주차 가능 여부를 확인하고, 원하는 시간에 정확하게 예약이 가능한 기능을 만드는 게 중요합니다.

또한 어플리케이션 및 웹 환경에서 단순한 UI를 통해 쉽게 사용할 수 있어야 하며, 결제 과정이 간편하고 쉽게 이루어지기를 기대합니다.

서비스 이용 중에 오류가 적고, 예약 정보 및 이용 내역이 정확하게 관리되는 신뢰성 또한 중요한 요소가 될 것 같습니다.

추가적으로 알림 기능을 통해 예약 시간, 주차 종료 시간을 안내 받기를 기대합니다.


## **(2) 개발자 혹은 유지보수 담당자가 원하는 기대치는 무엇인가?**

개발자 및 유지보수 담당자는 시스템이 확장성과 유지보수성, 가동성이 높은 소프트웨어 품질을 가진 구조로 설계되기를 원합니다.

예를 들어 주차장 수나 사용자 수가 급증하더라도 안정적으로 운영될 수 있도록 모듈화된 프로그램 구조가 필요합니다.

또한 코드의 가독성이나 일관성이 유지되어야 하며, 기능 추가나 수정이 쉬워야 합니다.

DB 구조는 효율적으로 설계되어야 하며 장애 발생 시 빠르게 원인을 파악하고 대응할 수 있는 모니터링 기능이 필요합니다.

보안 측면에서도 사용자 정보와 결제 정보 등이 안전하게 보호될 수 있도록 설계되어야 합니다.


## **(3) 개발 조직의 관리자가 원하는 기대치는 무엇인가?**

개발 조직의 관리자는 시스템이 기간 내에 안정적으로 개발되고, 운영 비용이 효율적으로 관리되기를 기대합니다.

또한 시스템이 사용자에게 높은 만족도를 이끌어내어 서비스 이용률이 증가하는 것을 기대합니다.

오류나 문제가 발생했을 시 빠르게 대응할 수 있는 체계가 갖추어져야 하며, 안정적인 서비스 운영이 이루어지기를 기대합니다.

그리고 향후에 서비스가 확장했을 시를 고려하여 유연한 구조를 갖추어 운영하여야 합니다.

마지막으로 보안 사고나 소프트웨어 사고 없이 운영되어서 기업의 신뢰를 유지하거나 높이는 것을 기대합니다.
